# Checked-in invented snapshot

Every number and figure here uses independently invented inputs. SPY and QQQ
are fixture roles, not actual ETF histories.

This is a compact subset of a 234-file complete generated run. It retains the
report, all 288 metric rows, all 96 paired intervals, all training diagnostics,
features, targets and successful model snapshots, plus the base-scenario HMM
and Kalman decisions/trades/ledgers for both assets. Other scenario ledgers and
other methods' ledgers are generated by the reproduction command below; they
are not checked in. No experiment result is selected out of the metrics table.

```bash
python -m strategy_lab.regimes --demo --output local-runs/regimes
python tools/verify_regime_run.py local-runs/regimes
python tools/verify_regime_run.py reports/regimes-synthetic
```

The snapshot verifier checks every retained fingerprint and independently
reconstructs the four retained accounts. The complete-run verifier reconstructs
all 72 model accounts. The complete original run manifest is fingerprinted in
this snapshot manifest; the snapshot manifest enumerates only files present
here. Generation timestamps and environment records may differ across runs;
locked-environment numerical CSVs and parameter snapshots are reproducible.

Source, model-account and data limitations are described in
[the methods](../../docs/REGIME_RESEARCH.md) and
[provenance](../../docs/REGIME_PROVENANCE.md). Current-vintage real ETF prices,
figures and result summaries are outside this snapshot and remain private.
