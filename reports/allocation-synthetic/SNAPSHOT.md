# Invented allocation snapshot

All prices, numerical results, parameters and figures here are independently
invented. ETF symbols name roles, not actual ETF observations.

This compact snapshot retains all 552 metric rows, 144 paired rows, every
optimization/perturbation summary, all optimization events/parameter snapshots/
forecast perturbations, primary target schedules and the six primary base-case
accounts (5 bp costs, 0% cash). Large event and account files use deterministic
`.gz` compression; decompressed fingerprints link them to the complete original
450-file run. Other sensitivity/cost/cash account details are regenerated by the
CLI; none of their summary results is omitted from the metrics table.

```bash
python -m strategy_lab.allocation --demo --output local-runs/allocation
python tools/verify_allocation_run.py local-runs/allocation
python tools/verify_allocation_run.py reports/allocation-synthetic
```

The snapshot audit reconstructs six retained accounts; the complete audit
reconstructs all 138. Generation timestamps/environment metadata can differ;
locked-environment numerical files and parameters are reproducible. No real ETF
observations, estimated real parameters or derived findings are part of this
snapshot. Read the [methods](../../docs/ALLOCATION_RESEARCH.md) and
[provenance](../../docs/ALLOCATION_PROVENANCE.md) before interpreting any curve.
